Local GPT: Offline Chat Assistant for Our Organization

Stack: Streamlit (web interface) + Ollama (local model server) File: app.py Connectivity: None required after setup. All processing stays on our own hardware.

1. Overview

Local GPT is a ChatGPT-style web application that runs entirely inside our network. Staff open it in a browser, pick a model, and chat. Prompts, documents and answers never leave the organization, because the app only talks to an Ollama server running on a machine we control.

Why it exists

  • Keep sensitive internal text and files off third-party cloud services.
  • Work without internet access.
  • No per-user or per-token fees. Cost is limited to our own hardware.
  • Full control over which models are offered and how they behave.

2. Architecture

Staff browser  --->  Streamlit app (app.py)  --->  Ollama server  --->  Local model files
 (LAN)               port 8501                     port 11434          (~/.ollama/models)
Component Role
Browser Chat interface. Needs only network access to the app server.
Streamlit Renders the UI, manages sessions, builds prompts, streams replies.
Ollama Loads models and generates text through its /api/chat endpoint.
chat_history/ Local JSON files, one per user, holding saved conversations.

The app calls two Ollama endpoints: GET /api/tags (list installed models) and POST /api/chat (streamed generation).

3. Features

  • Streaming replies as the model generates them.
  • Model picker populated automatically from installed Ollama models.
  • Adjustable settings: system prompt, temperature, context window (2K to 32K tokens).
  • Multiple chats per user with automatic titles, switching, deletion and Markdown export.
  • Persistent history stored locally per user name.
  • Chat with a document: upload .txt, .md, .csv, .json, .py or .pdf. The text (up to 60,000 characters) is added to the model's context.
  • Optional password gate through the APP_PASSWORD environment variable.
  • Clear error messages when Ollama is not running or has no models.

4. Requirements

Software

  • Python 3.9 or newer
  • Ollama installed on the server
  • Python packages: streamlit, requests, and optionally pypdf for PDF uploads

Hardware (approximate guide)

Model size Memory needed (4-bit quantized) Typical use
1B to 3B 2 to 4 GB Fast, light drafting and Q&A
7B to 8B 5 to 8 GB Good general assistant
13B to 14B 9 to 12 GB Stronger reasoning and writing
30B to 70B 20 to 48 GB Highest quality, needs a large GPU or lots of RAM

A GPU with enough VRAM gives much faster replies than CPU only. More concurrent users means slower responses, so size the machine for peak use.

5. Installation

5.1 With internet (simple)

pip install streamlit requests pypdf
ollama pull llama3.1
streamlit run app.py

5.2 Fully offline (air-gapped server)

On a machine with internet:

pip download streamlit requests pypdf -d wheels
ollama pull llama3.1

Copy to the offline server: the wheels/ folder, app.py, the Ollama installer, and the Ollama models folder (~/.ollama/models on Linux and macOS, %USERPROFILE%\.ollama\models on Windows).

On the offline server:

pip install --no-index --find-links wheels streamlit requests pypdf
ollama serve
streamlit run app.py

5.3 Turn off Streamlit telemetry

Create .streamlit/config.toml:

[browser]
gatherUsageStats = false

6. Configuration

All options are environment variables, set before launching.

Variable Default Purpose
OLLAMA_HOST http://localhost:11434 Where the Ollama server is
APP_PASSWORD empty (no login) Require a shared password
CHAT_HISTORY_DIR ./chat_history Where chats are saved
APP_TITLE Local GPT Name shown in the interface

Example (Linux/macOS):

export APP_PASSWORD="choose-a-strong-password"
export APP_TITLE="Org Assistant"
streamlit run app.py --server.address 0.0.0.0 --server.port 8501

7. Usage

  1. Open http://<server-ip>:8501.
  2. Enter your name in the sidebar. This keeps your chats separate from others.
  3. Choose a model.
  4. Type a message and press Enter.
  5. Use New chat to start a topic, the chat list to switch, Export to download a chat, and Delete to remove one.
  6. To ask about a file, open Chat with a document and upload it. Use Remove document when finished.

Tips

  • Keep the system prompt short and specific.
  • Lower temperature (0.2 to 0.4) for factual work, higher (0.8 to 1.0) for creative writing.
  • Raise the context window only if you need long documents. It uses more memory.

8. Security and Privacy

  • The name field is not authentication. It only separates chat history. For real access control use APP_PASSWORD, or place the app behind a reverse proxy with SSO or LDAP.
  • Chat history is plain text on the server. Restrict access to chat_history/ and include it in backups if needed.
  • Use HTTPS inside the LAN if passwords or sensitive content cross shared networks. A reverse proxy such as Nginx or Caddy can provide this.
  • Do not expose the app or port 11434 to the internet. Ollama has no built-in login.
  • Models can produce incorrect or fabricated answers. Staff should verify important output.

9. Running as a Service (Linux example)

# /etc/systemd/system/localgpt.service
[Unit]
Description=Local GPT (Streamlit)
After=network.target ollama.service

[Service]
WorkingDirectory=/opt/localgpt
Environment=APP_PASSWORD=change-me
ExecStart=/usr/bin/python3 -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501 --server.headless true
Restart=always

[Install]
WantedBy=multi-user.target

Enable with sudo systemctl enable --now localgpt.

10. Troubleshooting

Problem Likely cause and fix
"Cannot reach Ollama" Ollama is not running. Start it with ollama serve, or check OLLAMA_HOST.
Model list is empty No models installed. Run ollama pull <model> (or copy the models folder).
Very slow replies Model too large for the hardware, or running on CPU. Use a smaller model or add a GPU.
Out of memory errors Lower the context window or choose a smaller model.
PDF upload fails Install pypdf. Scanned PDFs without a text layer cannot be read.
Others cannot connect Start with --server.address 0.0.0.0 and open the firewall for port 8501.
